# First-use external validation gate — DLULIB (provisional, not yet executed)

**Candidate source:** Nguyen-Huu et al., *DLULIB: a multi-floor WiFi Fingerprinting dataset for indoor positioning in Dalat University library*, *Data in Brief* (2026), DOI **10.1016/j.dib.2026.113292**; dataset Zenodo DOI **10.5281/zenodo.19434712** (https://zenodo.org/records/19434712). **Identified 19 November 2026.** It was not among the source/external datasets identified in the recovered Stage 1–8 evidence ledger, but absence from this local record is not proof that no researcher had viewed it earlier. Status: **provisionally new target, not yet opened/scored**.

## Independently documented facts, not model outcomes

The publisher reports 3 floors in one Vietnamese university library, 17 APs, 650 RPs, **13,000 training fingerprints + 6,500 testing fingerprints**. Excel files are separated by floor into full training, averaged training, and test subsets. Importantly, the independently collected test fingerprints are taken at the **same physical RPs as training**, so the benchmark can assess new-building/device/signal transfer but **does not test positioning at spatially unseen locations**. Its published baselines are not JEPFormer error-forecast evaluations. The Zenodo package lists **DLULIB.zip**, 6.1 MB, MD5 `e30071a2f4bf14ed96f5f46f20468ac3`. The Zenodo record did not display a specific machine-readable dataset license in the inspected page; do not redistribute the original archive until confirmed.

## Pre-score evaluation lock

1. Download official `DLULIB.zip` into a private local folder; verify pinned Zenodo MD5 and independent SHA-256. Do not publish raw Excel worksheets, identity columns, indoor coordinates, or derived geometry in this project's public Git history.
2. Run the **source-only archive file-layout gate** (`python -m jepformer.dlulib_gate /path/to/DLULIB.zip` via the provided CLI, or `audit_archive` API). It inspects ZIP filenames and hashes only—**it does not open any test worksheet**. The gate is not validation.
3. Extract training-only and test-inference-only files to separate access-controlled paths. Split each test worksheet into AP RSS/observable columns and sealed X/Y reference labels using a narrow, independently audited parser. Record checksums of both streams; verify an inference process cannot open the sealed labels.
4. Produce six candidate coordinates from **training data only** using source-committed definitions and fixed hyperparameters: CatBoost, Extra Trees, Gradient Boosting, KNN, Random Forest, WKNN. A floor-specific analysis may use the known test-session floor provided by the dataset file name, but must not claim floor prediction. No test coordinate, test positioning error, participant identifier, phone label, or future RSS is permitted as a candidate-model or error-model input.
5. Reproduce the exact **14 scan**, **12 geometry**, **7 candidate-local** feature computations, including original AP-observed masks, RSS missingness conventions, diagnostic anchor and local radio-map matching. Require synthetic and source-regression equivalence tests. **Do not substitute approximate hand-crafted features.** Source-model normalization remains fixed to its training-only saved parameters; models and six estimator identities remain unchanged.
6. Freeze JEPFormer and CatBoost weights **before** inference, and record predictions/coverage/exclusions/scan IDs and SHA-256. Only after both model predictions are frozen and archived can the separate scorer read test XY, compute realized error, and evaluate MAE, conditional severe-error MAE (>= 10 m), bias, AUROC/AP, RP-cluster intervals, floor-wise results and complete coverage.
7. Report all three floors and all candidate methods, without post hoc thresholds, floor exclusions, retuning, or model selection after labels become visible. Aggregate statistics should be accompanied by repeated-measure physical-RP uncertainty and source-to-target protocol deviations. One building/three floors is **one new collection**, not three independently acquired external dataset families.
